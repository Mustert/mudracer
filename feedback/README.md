# Bugs und Ideen

Hier landen Meldungen aus dem Spiel: im Dev-Server (`npm run dev`) am PC F8 drücken, BUG oder IDEE / FEATURE ankreuzen,
beschreiben, SPEICHERN (Strg+Enter). Im veröffentlichten Spiel gibt es das Fenster nicht.

Jede Meldung ist eine Datei `bug_<datum>_<uhrzeit>_<strecke>.md` bzw. `feature_…md` mit dem Text, dem Stand des Spiels
(Strecke, Runde, Platz, Modus, Schwierigkeit, Build-Commit) und einer Tabelle aller Autos (Lage, Winkel, Tempo, Runde, Platz),
dazu das Bild als `.jpg`.

Abgearbeitete Meldungen werden in `ANALYSE.md` eingetragen (Bugs als Befund, Ideen im Abschnitt I) und hier gelöscht.
