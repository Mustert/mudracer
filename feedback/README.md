# Eingang: Bugs, Ideen und Testmeldungen

Hier landen Meldungen aus dem Spiel: im Dev-Server (`npm run dev`) am PC F8 drücken, BUG, IDEE / FEATURE oder TEST / ABNAHME ankreuzen,
beschreiben, SPEICHERN (Strg+Enter). Im veröffentlichten Spiel gibt es das Fenster nicht.

- **BUG** (`bug_…`): etwas ist kaputt oder falsch.
- **IDEE / FEATURE** (`feature_…`): etwas Neues soll es geben.
- **TEST / ABNAHME** (`test_…`): Rückmeldung zu etwas, das Claude gerade umgesetzt hat und das du ausprobierst (passt, passt noch nicht, gefällt nicht).

Jede Meldung ist eine Datei `<art>_<datum>_<uhrzeit>_<strecke>.md` mit dem Text, dem Stand des Spiels
(Strecke, Runde, Platz, Modus, Schwierigkeit, Build-Commit) und einer Tabelle aller Autos (Lage, Winkel, Tempo, Runde, Platz),
dazu das Bild als `.jpg`.

Das hier ist nur der Eingang, keine Liste. Die einzige Liste ist `Obsidian/Mudracer/ROADMAP.md`. Meldungen bleiben hier liegen, bis der Nutzer sagt
„sichte den Eingang“; dann ordnet Claude sie nach dem Skill `roadmap` in die Roadmap ein und löscht die Dateien.
