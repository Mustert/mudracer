# Bug-Meldungen

Hier landen die Meldungen aus dem Spiel: im Dev-Server (`npm run dev`) F8 drücken, beschreiben, SPEICHERN.
Jede Meldung ist eine Datei `<datum>_<uhrzeit>_<strecke>.md` mit dem Text, dem Stand des Spiels (Strecke, Runde, Platz, Modus,
Schwierigkeit, Build-Commit) und einer Tabelle aller Autos (Lage, Winkel, Tempo, Runde, Platz), dazu das Bild als `.jpg`.

Im veröffentlichten Spiel gibt es keinen Server: dort bleiben die Meldungen im Spielstand (`mudracer-bugs`, die letzten 20)
und kommen über KOPIEREN (Markdown, ohne Bilder) oder DATEI (`mudracer-bugs.json`, mit Bildern) im F8-Fenster heraus.

Erledigte Meldungen werden in `ANALYSE.md` eingetragen und hier gelöscht.
